# Mikyla Cabillo — Portfolio & CV

A responsive personal CV website for Mikyla Erica P. Cabillo, an Information Technology student, UI/UX designer, and aspiring web developer. It features a yellow-and-black visual identity, accessible navigation, subtle scroll reveals, and sections for education, skills, work, leadership, and selected projects.

## Technologies

- HTML5
- CSS3 (responsive layout, motion preferences, custom styling)
- Vanilla JavaScript (mobile navigation and scroll reveals)
- Vercel (static deployment)
